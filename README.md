# Вкусный знак — сборка с оригинальными PNG

## Запуск
Распакуйте архив целиком. Для просмотра дизайна откройте index.html.
Для камеры на компьютере запустите в папке проекта:

```sh
python -m http.server 8000
```

Откройте http://localhost:8000 и разрешите камеру.
На телефоне разместите папку на HTTPS-хостинге. Обычный HTTP-адрес компьютера в локальной сети не подходит для getUserMedia.
При отказе камеры доступна загрузка фотографии.

## Состав
- index.html — четыре состояния: приветствие, камера, анализ, результат.
- styles.css — базовые стили.
- polish.css — финальная адаптация, фон #FCF9E8, размеры и анимации оригинальных картинок.
- app.js — камера, загрузка снимка, браузерная модель и переход в предложения.
- assets/mascot-hero.png — оригинал из вашего архива, 700 × 692, прозрачность сохранена.
- assets/mascot-result.png — оригинал из вашего архива, 300 × 288, прозрачность сохранена.

Картинки уже включены: копировать или переименовывать их не нужно.
Дополнительных подложек под ними нет — используются подложки самих иллюстраций.

## Ограничения прототипа
- Нужен интернет для Google Fonts, TensorFlow.js и MobileNet.
- Фото анализируется в браузере, код не загружает его на сервер.
- MobileNet — общая модель классификации, не распознаватель ассортимента магазина.
- Подключённые категории: банан, апельсин, брокколи, огурец, сладкий перец. Даже их распознавание может ошибаться. Помидор в данных оставлен как пример экрана, распознавание помидоров этой моделью не гарантируется.
- Низкая уверенность или неподдерживаемый класс дают «пока не узнал» без выдуманных БЖУ.
- Пищевая ценность — примерные справочные значения на 100 г продукта, не измерение по фотографии и не данные конкретного SKU. Углеводы в этих справочных примерах включают клетчатку.
- Анализ отображается минимум 7,5 секунды; первая загрузка модели требует дополнительного времени. Загрузка и классификация имеют тайм-ауты.
- Фраза о маленьком маскоте — сценарий персонажа. В этой версии нет обучения по сканам, сохранения исправлений и сервиса начисления подарков.
- Кнопка бонуса вызывает tsxapp://app/personal_offers_list. Вне установленного приложения этот переход может не поддерживаться. Реальный бонус не начисляется.
- Маленькая картинка с помидором — иллюстрация персонажа, не изображение распознанного товара.

## Проверка
Проверены загрузка всех PNG, отсутствие ошибок JavaScript и размещение четырёх состояний на 360×640, 375×667, 390×844, 430×932 и настольном 1280×900.
Сценарий выбора фото → анализ → результат тестируется с подменой ответа модели; это проверка интерфейса, не измерение точности распознавания.
Реальную камеру и точность модели необходимо дополнительно проверить на целевых устройствах.
При очень маленькой высоте или увеличении текста допускается вертикальная прокрутка вместо обрезания кнопок.
